# 📝 CRUD Application

A full-stack task management application built using the **MERN stack**. 
The application allows users to create, read, update, and delete tasks through a React frontend connected to a Node.js and Express.js backend.

---

## 🚀 Features

- ➕ Create new tasks
- 📋 View all tasks
- ✏️ Update existing tasks
- 🗑️ Delete tasks
- 🔄 Update task status
- 💾 Persistent data storage using MongoDB
- 🔗 RESTful API integration
- 📱 Responsive user interface
- ⚡ React-based frontend
